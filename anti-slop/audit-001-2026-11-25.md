## Findings

1. **[HIGH | R-25 — Color Contrast]** `src/components/ClockWheelSelector.tsx` sets inline `opacity: Math.max(0.28, visibilityWeight)` on `.clock-station-anchor`, reducing the outermost visible wheel stations (`MLFQ`, `SRT` on desktop) below the WCAG AA 4.5:1 text contrast floor.
2. **[HIGH | R-39 — Accessible Semantics]** `src/components/ClockWheelSelector.tsx` applies `aria-hidden={!isVisibleArc && !isSelected}` to `<button role="radio">` elements, hiding off-arc stations from the `radiogroup` item count reported to screen readers even though all ten algorithms are reachable via `ArrowUp`/`ArrowDown`.
3. **[MEDIUM | R-01 / R-13 / R-31 — Purpose-Gate Elevation & Glow]** `src/index.css` applies `box-shadow: 0 8px 24px rgba(0, 0, 0, 0.28)` on `.is-selected .station-label-wrap` and `box-shadow: 0 0 12px var(--dial-glow-core)` on `.clock-focal-needle` without a written elevation/glow rationale comment in source (alongside the primary radial hub glow in `ClockArtwork.tsx`).
